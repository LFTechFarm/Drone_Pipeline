# 🛰️ UAV Microplot Extraction & Vegetation Index Pipeline

This repository provides a complete Python/Jupyter workflow to:

1.  🎯 **Crop and rotate microplots** from RGB and multispectral (MSP)
    orthomosaics.\
2.  📦 **Generate stacked RGB+MSP microplot cubes**.\
3.  🌱 **Compute vegetation indices** (NDVI, NDRE, GNDVI, SAVI, MSAVI,
    EVI, etc.).\
4.  📊 **Extract summary statistics** (mean, median, min, max, std).\
5.  🖼️ **Visualize results** for quality control and trait analysis.

------------------------------------------------------------------------

## ⚙️ Workflow Overview

### 🔹 1. Microplot Cropping & Rotation

-   Reprojects polygons\
-   Extracts central percentage of plot (`CENTER_PERCENT`)\
-   Computes orientation\
-   Crops and rotates RGB/MSP\
-   Builds 8‑band stack:
RGB:
1. Red
2. Green
3. Blue

Multispectral:
5. Blue (MSP)
6. Green (MSP)
7. Red (MSP)
8. Red Edge
9. NIR

### 🔹 2. Vegetation Indices

Computed indices include:

-   🌿 NDVI\
-   🌾 NDRE\
-   🍃 GNDVI\
-   🟢 SAVI / OSAVI\
-   🌱 MSAVI\
-   🌍 EVI / EVI2\
-   💧 NDWI\
-   🔥 NDMI\
-   🌈 VARI\
-   ☘️ MCARI\
-   🌟 MTVI2

Statistics per microplot:

-   Mean\
-   Median\
-   Min\
-   Max\
-   Std

Exported to:

    microplots_output/indices/microplots_indices_summary.csv

------------------------------------------------------------------------

### 🔹 3. Visualization

The notebook provides a helper function:

    plot_index_stats(df)

This produces bar charts for all indices across all microplots.

------------------------------------------------------------------------

## 🔧 Customization

-   **Plot naming:**\
    `PLOT_ID_FIELD = "id"`

-   **Central area cropping:**\
    `CENTER_PERCENT = 50.0`

-   **Add new vegetation indices:**\
    Edit `INDEX_FUNCS`

-   **Sensor with different band order:**\
    Update `MSP_BAND_INDEX`

------------------------------------------------------------------------

## ⚠️ Notes

-   GeoJSON is automatically reprojected to match raster CRS.\
-   Invalid pixels cleaned using a "sum of bands \> 0" mask.\
-   Rotation uses `expand=True` to avoid clipping.
